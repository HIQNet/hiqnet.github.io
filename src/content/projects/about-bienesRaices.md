intro: >-
  Se desarrolló una aplicación móvil enfocada en la compra y venta de bienes
  raíces, permitiendo a usuarios buscar, publicar y gestionar propiedades de
  forma sencilla y eficiente.
challenges:
  - >-
    Crear una interfaz intuitiva para usuarios con distintos niveles de
    experiencia tecnológica.
  - >-
    Facilitar el filtrado eficaz de propiedades según criterios clave como
    ubicación, precio y tipo.
  - >-
    Garantizar que el proceso de publicación y contacto sea rápido y confiable
    para vendedores y compradores.
solution: >-
  Se implementó una app con funcionalidades de búsqueda avanzada, filtros
  personalizados, y herramientas para que los vendedores puedan subir fotos,
  descripciones detalladas y datos de contacto. La plataforma fue diseñada para
  conectar fácilmente a ambas partes y reducir los pasos en el proceso de
  compraventa.
results:
  - Mejora en la experiencia del usuario al buscar o publicar propiedades.
  - >-
    Mayor visibilidad para los vendedores y rapidez en la comunicación con
    posibles compradores.
  - >-
    Optimización del proceso de transacción inmobiliaria, haciéndolo más ágil y
    accesible.
