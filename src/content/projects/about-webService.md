intro: >-
  El proyecto consiste en el desarrollo del Back-End de una aplicación web
  para la startup <strong>NumerIQ</strong>, una plataforma educativa centrada
  en brindar tutorías personalizadas de matemáticas para estudiantes que buscan
  reforzar sus conocimientos en esta materia.
challenges:
  - >-
    Crear una infraestructura robusta y escalable que soporte sesiones de
    tutoría personalizadas.
  - Diferenciarse en un mercado saturado de plataformas educativas.
  - >-
    Integrarse como parte de un ecosistema competitivo sin replicar las
    funcionalidades genéricas de otras plataformas como Coursera o Udemy.
solution: >-
  Se diseñó y desarrolló el Back-End de la plataforma utilizando tecnologías
  modernas, con un enfoque en escalabilidad, seguridad y eficiencia. Se
  implementaron funciones clave como la gestión de usuarios, sesiones de
  tutoría, control de progreso académico y una arquitectura preparada para
  futuras integraciones con herramientas educativas.
results:
  - Plataforma lista para ofrecer tutorías personalizadas de manera eficiente.
  - >-
    Base tecnológica sólida para escalar el proyecto y agregar nuevas
    funcionalidades.
  - >-
    Diferenciación clara en el mercado al enfocarse exclusivamente en
    matemáticas, lo que brinda una ventaja competitiva frente a plataformas
    generalistas.
